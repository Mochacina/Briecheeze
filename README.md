# Briecheeze: 쾌적하고 안전한 시청 환경을 위한 브라우저 강화 도구

## 개요 *Overview*

Briecheeze는 네이버 스트리밍 플랫폼 시청 경험을 최상의 수준으로 끌어올리기 위해 설계된 브라우저 확장 프로그램입니다. 사용자의 소중한 네트워크 자원을 보호하고, 번거로운 조작 없이도 항상 최적의 환경에서 방송을 즐길 수 있도록 돕는 것을 목표로 합니다.

## 주요 기능 *Features*

- **다중 계층 필터링 시스템**
  - 네트워크 요청 단계에서 불필요한 서버 URL을 차단하여 유저 사용 경험을 향상합니다.

- **네트워크 최적화 및 개인 정보 보호**
  - 안전한 브라우저 에이전트를 적용하여 불필요한 트래픽 발생을 최소화합니다. 이를 통해 사용자의 네트워크 대역폭을 절약하고 잠재적인 개인 정보 노출 위험을 줄여줍니다.

- **시청 환경 제어**
  - **자동 고화질 설정:** 방송 입장 시 매번 화질을 바꿀 필요 없이, 항상 선호하는 최고 화질(1080p)로 자동 설정 및 유지합니다. 이 기능은 ON/OFF 가능합니다.
  - **자동 음소거 해제:** 방송에 입장할 때마다 음소거를 해제해야 하는 번거로움을 없애줍니다. 이 기능은 ON/OFF 가능합니다.
  - **자동 볼륨 설정:** 자동 음소거 해제 기능과 연계하여, 자동으로 볼륨 레벨을 설정합니다.
